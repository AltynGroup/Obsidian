# Altyn Ecosystem

Altyn is a blockchain-oriented ecosystem combining cryptocurrency,
mining, rewards, wallet functionality and community services.

## Main components

- ALTYN — Solana token.
- ZeroChain — Litecoin-based UTXO blockchain.
- Altyn Multiverse — participation and rewards game.
- Altyn Wallet — wallet functionality.
- Altyn Swap — cryptocurrency exchange functionality.
- Cloudflare Workers and Durable Objects — backend infrastructure.
- Telegram Mini App — user interface and integration.
